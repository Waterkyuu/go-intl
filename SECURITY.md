# Reporting a security vulnerability

Report a suspected vulnerability privately by emailing [the project maintainer](mailto:kerwinzheng853@gmail.com) with `go-intl security report` in the subject. Keep sensitive details out of public issues and pull requests while the report is being investigated.

Include the affected version or commit, the component involved, the impact on an application, and a minimal example if available. Remove credentials, personal data, and production translations from any example.

For ordinary bugs and formatting differences, use the [issue templates](https://github.com/Waterkyuu/go-intl/issues/new/choose).
