# Code of conduct

Everyone participating in go-intl issues, pull requests, reviews, and other project spaces should be able to contribute regardless of experience, background, or identity.

Discuss the code and its effects. Explain a disagreement with an example, test, or measurement. Ask for clarification when intent is unclear, and give people room to correct mistakes.

Harassment, threats, discriminatory remarks, personal attacks, and disclosure of another person's private information are unacceptable.

## Reporting a concern

Send a private report to [the project maintainer](mailto:kerwinzheng853@gmail.com). Include a link or description and enough context to locate the interaction. If the concern involves the maintainer, you can also [report the interaction to GitHub](https://github.com/contact/report-abuse).

Maintainers may edit or remove harmful content, lock a discussion, or restrict participation according to the severity and repetition of the behavior.
